# telegram-parser

Набор скриптов для Mac: экспорт истории **групповых** чатов Telegram за выбранный период. На выходе два файла — читаемый `.txt` и структурированный `.json`. Медиа не скачиваются: в тексте остаются пометки вроде `[фото]` или `[файл: report.pdf]`.

Готовые файлы лежат в `~/Downloads/telegram-export/`.

Python отдельно ставить не нужно: это делает `uv`.

## Что понадобится

- компьютер Mac;
- аккаунт Telegram;
- значения `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — их передаёт тот, кто дал вам этот набор. Регистрировать своё приложение на my.telegram.org не нужно.

## 1. Скачать набор

На странице репозитория нажмите **Code → Download ZIP**, распакуйте архив в удобную папку (например, в Загрузки). Все команды ниже выполняются **из этой папки**.

## 2. Установить uv

`uv` сам ставит нужную версию Python. Homebrew не требуется.

Откройте Terminal (Программы → Утилиты → Terminal) и выполните:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Закройте окно Terminal и откройте снова, чтобы команда `uv` появилась в PATH. Проверка:

```bash
uv --version
```

## 3. Заполнить .env

В папке проекта скопируйте пример настроек:

```bash
cp .env.example .env
```

Файлы, чьё имя начинается с точки (`.env`, `.env.example`), Finder и многие редакторы скрывают. Откройте `.env` из Terminal в TextEdit:

```bash
open -e .env
```

Либо в Finder нажмите **Shift+Command+.** (точка) — скрытые файлы появятся, пока не нажмёте снова.

Вставьте полученные `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`. Строку `TELEGRAM_SESSION_STRING` пока оставьте пустой — её запишет вход.

## 4. Войти в Telegram один раз

Дважды щёлкните `Вход.command` в Finder. Либо в Terminal из папки проекта:

```bash
uv run login.py
```

Сначала заголовок `----- Генератор строки сессии Telegram -----`, затем QR-блок `----- Вход по QR-коду -----`:

```
Отсканируйте QR-код выше в приложении Telegram:
  Откройте Telegram → Настройки → Устройства → Подключить устройство
```

Если код истечёт, скрипт покажет новый: `QR-код истёк, вот новый.`

Если включена двухфакторная аутентификация, появится запрос: `Включена двухфакторная аутентификация. Введите пароль:`

После успешного входа: `Вход выполнен успешно!` и вопрос:

```
Записать строку сессии в .env автоматически? (y/N):
```

Введите `y` и нажмите Enter — в `.env` появится `TELEGRAM_SESSION_STRING=...`. Эту строку никому не показывайте: с ней можно войти в ваш аккаунт.

## 5. Экспорт

Дважды щёлкните `Экспорт чатов.command` в Finder — откроется Terminal и запустится экспорт из папки проекта. Либо в Terminal из той же папки:

```bash
uv run export.py
```

На экране заголовок `----- Экспорт истории Telegram -----`, затем меню:

1. `Введите часть названия чата для поиска (или Enter — показать все):` — пустой ввод показывает все группы.
2. `Выберите номер группы:`
3. Если это форум с темами — блок `Темы форума:` со списком и пунктом `Все темы`, затем `Выберите тему:`. Обычная группа этот шаг пропускает.
4. `Период экспорта:` — `Выберите вариант:` `1) Последние 7 дней`, `2) Последние 30 дней` или `3) Свой диапазон (ДД.ММ.ГГГГ)`. Для своего диапазона: `Дата начала (ДД.ММ.ГГГГ):` и `Дата конца (ДД.ММ.ГГГГ):`.
5. Сводка `----- Подтверждение выбора -----`.

Пока сообщения загружаются: `Загружено N сообщений…`. В конце: `Готово.` и пути к файлам. Если за период пусто: `За выбранный период сообщений не найдено.`

Обычная группа или одна тема: пара `.txt` / `.json` прямо в `~/Downloads/telegram-export/`. Все темы форума: подпапка с именем группы, отдельная пара файлов на каждую тему.

Когда экспорт (или вход) закончится, в окне будет `Нажмите Enter, чтобы закрыть окно.` Повторный экспорт — снова дважды щёлкните `Экспорт чатов.command`. Terminal вручную открывать не нужно.

## Устранение неполадок

### Чаты не найдены

Если поиск ничего не дал, скрипт пишет `Ничего не найдено. Показан полный список.` и показывает все группы. В списке только группы и супергруппы, где вы состоите. Каналы и личные переписки туда не входят.

Если групп нет совсем, на экране появится ошибка `Нет доступных групп для экспорта.`

### Неверные учётные данные

Сообщения, которые можно увидеть при входе или экспорте:

- `Ошибка: TELEGRAM_API_ID и TELEGRAM_API_HASH должны быть заданы в .env` — скопируйте `.env.example` в `.env` и вставьте значения, которые вам передали.
- `Ошибка: TELEGRAM_API_ID должен быть целым числом`
- `Ошибка: TELEGRAM_SESSION_STRING не задан в .env` и `Сначала выполните: uv run login.py`
- `Сессия недействительна. Выполните снова: uv run login.py` — снова запустите `Вход.command` (или `uv run login.py`)

### Не видно .env в Finder

Имя начинается с точки, такие файлы скрыты. В папке проекта в Terminal: `open -e .env`. В Finder: **Shift+Command+.**

### Telegram просит подождать (flood wait)

`Telegram ограничил запросы. Ждём N сек…` — не закрывайте окно. Скрипт сам подождёт и продолжит загрузку.

### Темы форума не показываются

Шаг `Темы форума:` появляется только у групп с включёнными темами. Обычная группа его пропускает (в сводке будет `без тем (обычная группа)`). Если темы должны быть, проверьте в Telegram, что у группы включён форум и что вы в этой группе.

### Файл .command не запускается

После распаковки ZIP macOS иногда снимает право на запуск. В Terminal из папки проекта:

```bash
chmod +x "Экспорт чатов.command" "Вход.command"
```

Если система пишет, что файл из интернета: правый щелчок по файлу → **Открыть** → **Открыть**.

### Команда uv не найдена

Закройте Terminal и откройте снова. Установщик кладёт `uv` в `~/.local/bin`. Если `uv --version` по-прежнему не работает, выполните скрипт установки ещё раз.
